# MC 版《无畏契约》狂徒皮肤绘制工作流

本文记录本次在 Blender 中制作紫金、EGO 和神罚狂徒皮肤的方法，适合继续为现有 MC 狂徒模型制作**静态贴图皮肤**。模型、UV、骨架和动画尽量沿用原工程；游戏内材质、动态特效和导出兼容性仍需另行验证。

## 1. 本次工程的基本情况

- 原预览工程：`D:\Projects\vandal-roundtrip\valorant-first-person-pack\00_九把枪械预览.blend`。
- 狂徒场景：`04_VANDAL`；动作场景：`E04_VANDAL_Actions`。
- 枪身：`Weapon_Body | 00_Showcase.003`；弹匣：`Weapon_Magazine | 00_Showcase.003`；另有备用弹匣。
- 原贴图为 256×256 RGBA，枪身和弹匣共用材质；UV 名为 `SourceUV`。新皮肤使用 2048×2048 RGBA PNG，沿用原 UV。
- 在该模型的**本地坐标**中，枪口朝 `+Y`，枪托朝 `-Y`，`Z` 轴向上。弹匣局部坐标大致为 `Y=0.325～0.895`、`Z=-0.487～0.171`。这些数字是本模型的测量值，换模型必须重新测量。
- 第 66 帧曾用于观察枪身和弹匣组合。其他模型或动画不一定适用这个帧号。

## 2. 准备与备份

1. 明确皮肤名称、配色和要参考的版本。优先使用清晰、无遮挡、接近正侧视的全枪图，保证枪口、枪托和弹匣都在画面内。保留来源记录。
2. 在 Blender 中确认当前场景、文件路径、物体、材质、贴图、UV、骨架、修改器及动画。特别检查枪身、弹匣和备用弹匣是否共用材质或网格数据；共享数据的修改可能影响其他场景。
3. **先另存工程副本**，并备份原图。原始打包图像应直接导出或复制，保留原有 RGBA；不要把经过色彩管理渲染的预览图当作原始像素。
4. 检查动画停止在适合观察的姿态。若启用了局部视图，确认枪身和弹匣都在局部视图中；否则弹匣可能只是被隐藏，不代表模型丢失。
5. 确定交付目标：静态展示、保留动画的 Blender 工程、单独 PNG，还是可在 MC 中使用的资源。最后一种还需要按项目实际导出流程和游戏环境测试。

## 3. 检查模型与 UV

1. 分别观察枪身、弹匣、备用弹匣的材质插槽与图像纹理节点，确认 Base Color 连接的是哪张图。
2. 保留 `SourceUV`，不要为了方便投影直接覆盖原 UV。先检查 UV 岛是否重叠、镜像、非常小或有零面积；共享 UV 区域可能让不同部位互相串色。
3. 若原贴图过小而细线无法表达，可在**保持 UV 不变**的前提下提高贴图分辨率。本次使用 2048×2048；是否适合最终 MC 管线需实际测试。
4. 绘制前规划色块、细节和透明区域。侧视图只提供一面信息，另一侧的文字方向、顶部和窄边需要单独检查，不能默认正确。

### 可选：导出本地几何和 UV 数据

下面的脚本在 **Blender 的 Python Console** 中运行，导出当前这把狂徒的静态本地坐标与 UV 三角形供外部绘图脚本使用。它读取网格数据，不改模型或 UV。对象名和输出目录只适用于本工程；运行前确认名称与路径。

```python
import bpy
import json
from pathlib import Path

out_dir = Path(r"D:\Projects\Mine_VALORANT\skin_work_folder\vandal_skin_work")
out_dir.mkdir(parents=True, exist_ok=True)
names = [
    "Weapon_Body | 00_Showcase.003",
    "Weapon_Magazine | 00_Showcase.003",
]
result = []
for name in names:
    obj = bpy.data.objects[name]
    mesh = obj.data
    uv_layer = mesh.uv_layers.get("SourceUV")
    if uv_layer is None:
        raise RuntimeError(f"{name} 缺少 SourceUV")
    mesh.calc_loop_triangles()
    result.append({
        "name": obj.name,
        "vertices": [list(v.co) for v in mesh.vertices],
        "faces": [
            {
                "v": list(tri.vertices),
                "uv": [list(uv_layer.data[i].uv) for i in tri.loops],
            }
            for tri in mesh.loop_triangles
        ],
    })
(out_dir / "geometry.json").write_text(
    json.dumps(result, ensure_ascii=False), encoding="utf-8"
)
print("已导出", out_dir / "geometry.json")
```

导出的是**未经过骨架变形的网格本地坐标**，适合使用本地空间进行贴图定位；观察动画姿态时，应另行查看骨架变形后的效果。上述对象顺序为枪身、弹匣，示例脚本依赖这个顺序。

## 4. 绘制新皮肤

### 方法 A：Blender 纹理绘制

1. 复制原材质和原图，创建新皮肤用的 RGBA 图像；不要直接覆盖原始资源。
2. 把新图像连接到复制后的材质，选择枪身或弹匣，进入 **Texture Paint（纹理绘制）**。在图像编辑器中确认当前绘制目标是新图像和正确的 UV。
3. 按“底色 → 主要色块 → 细线与标记 → 边缘修整”的顺序绘制。结合 UV 编辑器和 3D 视图，避免把一个 UV 岛的图案画到其他部位。
4. 启用适合像素风的采样方式。本次材质的图像节点使用 `Closest`；如果项目追求平滑效果，可根据实际游戏显示调整。
5. 保存 PNG，再打包进 `.blend`。Blender 中图像未保存时，保存工程不应被当成唯一备份。

### 方法 B：参考图投影到原 UV

本次 EGO 和神罚采用此方法：把参考图中的枪身侧面颜色投到现有网格，再写入原 UV 图集。它便于快速还原配色，但参考图的高光、阴影和透视也会被绘入贴图。

1. 使用上面的 `geometry.json` 获取每个三角形的顶点坐标和对应 UV。选取枪口、枪托、机匣、弹匣顶端等共同标志点，分别校准模型坐标与参考图像素的对应关系。
2. 对每个 UV 三角形进行栅格化；在三角形内用重心坐标插值出模型本地位置，再按校准后的侧视关系采样参考图颜色，写入 UV 贴图。
3. 注意 Blender UV 的 `V` 方向与常见 PNG 图像的像素 `Y` 方向相反；绘制时要做上下转换。
4. 对落在参考图轮廓之外的表面补合适的底色，清除被误投射的背景、阴影和挂饰。对零面积 UV 面单独检查；不能因为脚本跳过就假定它们不重要。
5. 可对 UV 岛外缘做少量颜色扩边来减少缝隙。本次示例使用约 3 像素；扩边前后应检查岛间重叠和串色，距离太近时需减少扩边或使用隔离掩码。
6. 检查左右两面、顶部和细边；单张侧面参考图不能保证背面文字方向正确，也不能自动还原立体结构或材质反光。

脚本中每张参考图的尺寸、位置、比例、背景识别阈值和补色均需单独校准。**不要把本次固定坐标直接套到其他图或模型。**

## 5. 透明通道与图像保存

该模型使用原贴图的透明区域控制部分表面显示。新图如果只保存为 RGB，透明贴片可能变成黑色方块或出现多余表面。

将原始 RGBA 图的 alpha 放大到新图尺寸，使用最近邻，避免插值改变透明边缘。以下示例使用 Python 的 Pillow；文件名按实际情况修改，输出到新文件，避免覆盖输入：

```python
from PIL import Image

color = Image.open("new_skin_rgb.png").convert("RGBA")
original = Image.open("original_weapon_rgba.png").convert("RGBA")
alpha = original.getchannel("A").resize(color.size, Image.Resampling.NEAREST)
color.putalpha(alpha)
color.save("new_skin_rgba.png")
```

在材质中保留或正确设置原有的 alpha 连接及透明显示方式，再从不同角度查看。注意，某些工作台预览方式和最终渲染对透明度的显示可能不同，需要用目标渲染方式复查。

## 6. 单独校准弹匣

1. 放大观察弹匣顶端、弯曲部分、侧面、底沿和拉环；同时看左右两侧。以**实际网格边缘**为准，不要只看贴图中的弹匣照片。
2. 如果参考图中的底盖、色块或金边落在弹匣内部，只重绘弹匣对应的 UV 区域，平滑调整其采样位置或重新画底盖。不要为补偿贴图错位而缩放模型本身。
3. 本次 EGO 的底部金边偏向内侧；修正时在弹匣下半部逐渐把采样用的本地 `Y` 坐标偏移，最大约 `0.12`，使金边移到真实底沿。该数值仅适用于本模型、这张参考图和当时的投影校准。
4. 弹匣 UV 和枪身 UV 可能有少量重叠；局部修改后回看枪身，确认没有串色。保留原 alpha，检查弹匣底部和拉环的透明区域。

## 7. 应用到 Blender 材质

1. 复制用于目标狂徒的材质，在复制品的图像纹理节点加载新的 RGBA PNG。
2. 把新材质分配给目标枪身、弹匣和备用弹匣，检查相关动作场景。分配前先确认网格数据是否被多个物体或场景共享；如需隔离版本，先复制相应网格数据或使用独立工程副本。
3. 在节点编辑器确认图像颜色连接到 Principled BSDF 的 Base Color，并保留正确的 alpha 连接；只更改 `Material.diffuse_color` 不足以改变节点材质的实际渲染。
4. 在图像编辑器保存 PNG，使用 Blender 的 **File → External Data → Pack Resources** 或图像的 Pack 功能打包图片，再另存 `.blend` 副本。节点要保持选中可绘制的图像纹理，便于继续编辑。

如果通过 `bpy` 操作，按节点的 `type` 查找节点，而不要依赖可能被翻译或改名的节点显示名称，例如：

```python
image_node = next(n for n in material.node_tree.nodes if n.type == "TEX_IMAGE")
shader = next(n for n in material.node_tree.nodes if n.type == "BSDF_PRINCIPLED")
```

新贴图若要替换已有图像，先确认图片没有未保存的手绘修改，并检查其他材质是否也引用该图片。

## 8. 检查与交付

### Blender 检查

- 看枪身左右两面、正上方和斜视角；检查颜色、文字、闪电、金边、UV 缝和背景污染。
- 放大弹匣的上半部、弯折处、底盖与拉环，确认图案覆盖真实几何；检查备用弹匣。
- 用有材质和透明显示的方式查看；若局部视图隐藏了某个物体，先排除显示设置问题。
- 播放静止、射击、换弹和检视等相关动画，确认枪身、弹匣、备用弹匣及贴图随骨架正常运动。此前展示图只验证了指定姿态，不代表所有动作已完成验证。
- 保存新 PNG 和 `.blend`，确认图像已打包，重新打开副本检查是否丢图。导出到 MC 后，再检查尺寸、透明度、贴图采样、模型绑定及动画。

### 两类工程

- **单枪动画工程**：保留原枪骨架、权重、NLA 动画与相应贴图，适合后续动画和导出验证。
- **展示工程**：本次使用变形后网格的静态副本排列多把枪，方便比较皮肤；它不等同于带骨架动画的游戏模型。

按皮肤名称和版本保存，不覆盖用户的原工程。制作预览图时标注皮肤版本；若是静态贴图模拟高光或闪电，不应称为已实现动态发光、音效或击杀特效。
