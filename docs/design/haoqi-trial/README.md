# MC_VALORANT · 豪气试炼 v3｜验证稿

**一页决策：玩家手射赚来一次爆发，爆发不能替玩家赚来下一次。** 心流仍然是唯一能力：满槽自动进入，玩家确认开火，沿用手中枪的伤害、射速和换弹。乐趣应当是「刚才那串头是我挣来的」，而非「我等系统替我打完」。以下按阅读顺序即完整交付。

## 1　体验目标（先于调数）

| ID | 玩家应感受到什么 | 验收线（均为设计假设；按人再按组汇总） |
|---|---|---|
| G1 | 新手在第一次试炼就懂得如何触发心流 | 首场、无卡、无教学代打，新手至少 75% 在有效时间 25 s 内首次满槽；未触发算失败。另记首次主动确认时间，区别「触发了」和「会用」。 |
| G2 | 锁定是奖赏，手射仍是主要工作 | 第 1、4 场，各技术档的「心流外有效击杀 / 全部有效击杀」个人中位数均 ≥50%；无击杀记 0。辅助击杀绝不入手射爆头统计。 |
| G3 | 构筑使同一个人打得更快 | 熟练、高手两档各自的**个人第 4 / 第 1 场 KPM 比值中位数**在 1.15–1.50 之间。同枪、无加时、指定合法构筑；用第 4 场避免把 Boss 机制时间混作成长。首场零杀记未通过，失败者也回放第 4 场。 |
| G4 | 最热闹时仍能辨认威胁并做对动作 | 每人至少 80% 的预警能在惩罚前做对首次响应；达线者 ≥75%。最高档相对低档的配对正确率中位数下降 ≤10 个百分点。静音、去色条件分别验，不用总体均值掩盖失败。 |
| G5 | 玩家体验到的心流提高，不只是 HUD 宣布「心流」 | 同人静默玩普通靶与试炼后，Flow Short Scale 核心均分的配对差中位数 ≥+0.5（7 点量表），且 ≥2/3 的人差值为正。问卷不作临床或技能迁移的证据。 |

**证据怎么读：** `配`＝本地项目一手配置/逻辑快照（实际读取，不是玩家实测）；`测`＝真人实测；`官`＝发布机构官方规范；`研`＝文献；`旧`＝v2 设计假设；`假`＝本稿候选、实验设置或验收线；`模`＝模拟或规则回放输出，**不算实测**。标记作用于所在表标题/整列/句；公式中的序号、单位换算、概率与状态边界是定义。无特别标注的设计表数字均为 `假`。

## 2　已有数据，以及需要你补什么

[一手数据表与公式](balance.md)：已核对当前版本的 **10 把枪**、伤害区域、护甲算法、两种挑战的刷新条件。[首批个人基线](baseline-2026-11-25.md)已有 10 局逐发记录，其中纯 Vandal 的 3 局为 86.02 KPM `测`。尚缺其他玩家、尤其是新手的同枪样本。

## 3–6　规格与验证入口

| 工作顺序 | 交付物 | 要作出的决定 |
|---|---|---|
| 3 · 公式与调参 | [结算顺序、豪气、金币、征程](balance.md) · [32 项被动逐项预算](cards.md) | 几何衰减必须覆盖爆头追加；锁定击杀不能续豪气、刷连击或靠补弹自给。先去掉发牌死路，再谈稀有度。 |

| 6 · 外部校验 | [签核人与删减顺序](validation.md#6-外部校验与删减) | 数学能证明有限，不能证明好玩、易读或贴合技术。 |
