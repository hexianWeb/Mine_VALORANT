## 3 · 每个事件只结算一次

**时钟与归属（G1/G2/G4）。** `t` 为未暂停、前台的有效真实秒；试炼截止、枪械节拍、换弹、心流、预警 HUD 均读它。仅让敌人运动/攻击准备按世界倍率 `w` 走，不改全局 timeScale 来实现慢放。进入/退出动效不抢输入；无靶不凭空开火。试炼边界优先于心流到期，到期优先于该刻开火；同刻威胁命中判定在玩家合法射击结算后，允许压线解围。黑市/节奏关不跑战斗计时。

程序接入点：沿用现有出生池、`onShotResolved` 和致死身份校验；现有 `lockChallengeConfig` 仅接受射击测试/消灭选项，90 s 终止与豪气账本应由试炼规则持有，不能把普通挑战的 50 杀完赛误当试炼截止。`wasFlow` 与 `aimAssistApplied` 分开记：G2 分子只数 **心流外** 有效击杀；即使玩家在流内手动切刀杀，也不算流外练枪成绩。辅助射线之外的手动击杀另留诊断标签。

1. 已成功发射且不属于菜单/拾取的一枪，快照 `wasFlow`、枪、弹序、移动、ADS 等。`hit` 指有有效伤害。Judge 的弹丸、Classic 的一次齐射只结算一次命中/打空；致死按不同 `spawnId` 去重，各给一次基础奖励。首发＝开场或上次有效击杀后的**第一枪**，且目标此前满血；打空也耗首发资格。多杀时首发/条件奖只给事件顺序中的首个合资格致死。补枪也走同一弹药、伤害及射速路径。
2. 先改倍率，再用同一倍率结算该枪全部致死。按扣弹前槽位判最后一发，再付击杀奖励，再补弹，再处理空仓。一枪多杀只检查一次满槽；入流从下一枪生效。刀可领击杀奖励，不涨枪械命中连击；面板、宝石、Boss 节点不产豪气/金币，不计击杀。

| 量（G1/G2/G3） | 公式/口径 |
|---|---|
| 连击 `M=m/100` | `m` 为整数，初始 100，上限 `C=300+100L高压`。手射命中：`m'=min(C,m+10×(1+银弹标志)+20L连杀×I连杀)`；连杀指距上次手射击杀 ≤2 s 且本枪致死。手射打空：普通 `max(100, floor(m/2))`，守护弹维持。满弹奖励生效的弹匣 `M_eff=min(C/100,M+0.5L满弹)`，不改底账。辅助期间冻结入流时 `M_eff`（只用于金币），退出从 100 重建。`+0.1/上限3/减半` 为 `旧`，顺序/冻结为 `假`。 |
| 每场上限 `Hj` | `180+10(j−1)`，各为 180/190/200/210/220 `假`；原 `300+75(j−1)` `旧`。各场独立，首场从 `0.60H` 开始（一次性，不带卡，不带入下一场），之后从 0 或开局饮料 `0.50H` 开始，二者取大不叠。这样调整的是第一次体验，不是每回合的充能速度。 |
| 手射击杀基础 `b` | 威胁 15、飞靶（含携靶）12、普通/金/宝石头杀 10 否则 6，**互斥**；出生带甲机器人另 +2 `旧`。分裂小靶、节点、面板不产资源。 |
| 豪气增减 | 手射每杀 `ΔG=b×M_eff×(1+Σ L_i a_i I_i)`；所有写作「×k」的豪气卡解释为 `a=k−1`，不互乘。Classic 枪饰的合资格右键同入括号，额外 +1。被动触发条件/系数见[卡表](cards.md)。先结算连续衰减 `−5L心境×Δt`，再结算打空代价 `−2L玻璃`，击杀得分后夹到 `[0,H]`。充满溢出丢弃。心流内增量与连续衰减均为 0。只在有合资格手射/刀杀的事件末检查入流，辅助不得重入。 |
| 锁定与辅助射击 | 仅锁屏内、未遮挡且可打的目标；威胁→飞靶→普通，同级按离准星角度、再按 spawnId。每批快照至多 `5+2L广角` 个 `旧`，一起收框；玩家确认一次，逐个打至死亡/失效，基础转靶间隔 0.10 s；实际射击不能早于武器下次合法开火。空仓换弹、失去视线跳过，松开/切枪可取消；新出生目标进下一批，须重新确认。准星引导不等于改伤害或穿墙。 |
| 击杀续时 | `q=.97−(.97−.80)×.70^L欲罢`；`R=.90×[1−(5/6)^L余韵]`，首层恰为 15%。这是 `x' = x+(目标−x)×比例` 的闭式。令 `D0=(5+L渐入)×[1+.60(1−.50^L玻璃)]` 秒。心流第 `n≥1` 杀：`δn=(.50+.20L人枪×I头杀)×q^(n−1)`；`deadline+=δn`。鸡/炮扣时，实际退出时 `G=R×H`、倍率复位、延长序号清零；场末直接丢弃。HUD 显示精度不参与判定。 |
| 为何一定会退 | 固定有限层数下，即使每次都是头，`D ≤ D0+(.50+.20L人枪)/(1−q)`；基础理论极限 7.5 s，第一次延长 0.50、第二次 0.40。没有写死时长或层数；有限不是短，极端叠层可能覆盖余下整场。`R<1` 且须新击杀，所以不能零事件重启。反例及实跑见[压力测试](simulation.md)。 |
| 金币（G3/G5） | 每枪入账 `Δ钱包=(1+L贪婪)×(1+I双倍饮料)×[I闪亮且命中 + Σ每杀{(1+I头杀)×M_eff×(1+4I金靶)+2L收割×I心流}]`；金靶不放大收割者；刀不算头杀。威胁为普通币基数，节点/分裂小靶无奖。闪亮弹按枪一次，含心流。账本保留百分币（倍率已离散），每次展示/可花为 `floor(余额)`，花费扣整数，征程末清空；无按弹丸取整套利。节奏金币单列，不吃战斗乘区。 |

**手算验收向量 `假/推导`：** 起始 `m=100`，Vandal 第一枪致死无甲头，持「一次定位」一层：`m=110，ΔG=10×1.10×2=22，金币=2.20`；下一枪打空 `m=100`。一枪打出 12 颗弹丸只有 1 颗命中非致死：`m` 仅 +10，金币 0（非闪亮）。余韵一层在第 2 场退出：`G=28.5<190`，不触发。程序对上三例才开始调参。
