# 附录 B｜32 张被动的强度预算（G2 / G3 / G5）

**一分是什么意思。** 同枪、同种子、同场景，比较「空构筑」与「只加此卡一层」的 90 s。令 `k=100×(有卡KPM/无卡KPM−1)`，`c=100×(有卡金币/无卡金币−1)`；**强度分 `P=.8k+.2c`**。这是试炼后还有商店可消费时的设计汇率 `假`，不是玩家效用的实测值；末场应另报纯 `k`，尤其不能按金币给「收割者」计战斗强度。预算按边际收益，不按特效规模；无层数上限不等于每层保底有收益。

**如何替换「假」分。** 这些 `k/c` 是用于排序实验的显式先验，不是从射速推出来的精确值。记录每人的「可触发次数→实际触发次数→省了几秒/多得多少币」。例如收割者额外币可直接核算为 `2×心流击杀数`；副手补给只能把**实际少做的换弹**折成时间，满匣溢出价值为零。用相同入场状态 A/B 回放得到 `k,c` 后整行替换；分别在手枪/步枪/慢狙、稀疏/密靶、零层与已有三层测边际。条件场净负、通用场超预算或普遍无触发的卡先下架，不用提高爆率掩盖。诅咒列的 `?` 表示试玩用暂定档；尚未验证的诅咒不进入首轮白盒。

**统治性判据 `假`：** 同档卡在至少两种武器、两种密度上，配对 KPM 和可花金币都不劣、至少一项高出 5%，并且不牺牲 G2，才称通用优选。现有模拟足以指出**哪种条件会打穿规则**，不足以宣布真人环境唯一最强卡。候选包若三张全低于本档预算，记录一次稀有度失信，宁可撤同档保证。
