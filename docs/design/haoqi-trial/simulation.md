# 附录 C｜可复算的模拟，不是通关预测

**问题是：不加新系统，已有的时序和卡能不能同时兑现 G1–G3？** [simulate.py](simulate.py) 是事件驱动的射击/补弹/转靶/心流模型。普通场和压力场刻意分开：同一张续时卡，面对「很久才看到下一批」和「准星前总有新靶」不是同一强度。

### 输入与复现

| 玩家代理 `假` | 手动转靶 s | 对当前靶再射意图间隔 s | 命中率 | 命中后头 / 腿概率 | 每批手动确认 s |
|---|---:|---:|---:|---:|---:|
| 新手 novice | 1.10 | .34 | .58 | .16 / .16 | .75 |
| 熟练 trained | .72 | .24 | .76 | .32 / .10 | .50 |
| 高手 expert | .48 | .17 | .89 | .53 / .06 | .37 |

其余命中为身体。时长独立均匀抖动 ±20% `假`；武器速率是下限约束，未射出不算打空。满血/甲目标保持到死亡；Vandal 普通/甲靶累计伤害门槛与本地护甲结算等价。锁定队列只射合法头，默认每批可见 2 靶；扫完再花转靶、收框及确认时间。密靶场每批 5 靶、已在视野，只花收框和确认。弹匣用尽必须等换弹；换弹可与确认等待重叠，退出心流不会取消恢复时间。三档不是依据段位实测出来的人群画像。

```sh
# 固定种子、每档每场 200 份；屏幕输出摘要、阈值扫描、单卡和密靶压力对照
python docs/design/haoqi-trial/simulate.py --seed 17 --runs 200 --audit
# 逐场而非均值：可指定自己想保存的 CSV 路径
python docs/design/haoqi-trial/simulate.py --seed 17 --runs 200 --csv trials.csv
```

**实验设计 `假`：** 每份完整计时 90 s；第 1–5 场固定进入，依次带入「渐入佳境 → 一次定位 → 熟练换弹 → 战术补给」前缀，代表能获得相应评级/牌时的一条构筑，不是平均随机征程。普通/甲靶混比见附录 A。只测战斗核心，**不模拟**随机发牌、商店消费、节奏、失败淘汰、威胁/Boss 占用、空间遮挡和真实转向物理；第 5 场是该阶段参数的训练靶对照。故这些数不能给出实际征程通关率、真实 Boss KPM 或所有卡的真实排名。脚本中的 `v2=True` 只还原所测旧规则；v2 未指定的确认/供靶口径两组相同，旧倍率暂按退出不重置。不要把对照组当作运行过 v2 客户端。

| 只改一项 | 熟练 | 高手 | 解释 |

先拿真人逐发记录确认高手的转靶耗时、一次定位触发率、每批可见数；再试是否将晚期收益从「更快再次满槽」移给枪械类。不要为追一个占比指标而让玩家等靶。

### 哪些组合会统治、哪些真的可能无限

| 条件 / 反例 | 证据与处理 |
|---|---|
| **旧人枪合一 + 旧战术补给 + 密集可见目标** | 原公式 `δ=.5q^(n−1)+.2L×头杀`。几何项收敛，但头杀常数项不收敛。若持续头杀率 `λ` 满足 `.2Lλ≥1` 且批间断档不耗尽已有余时，时钟就不再净减少。例：满甲也可一头的 Vandal，每杀返一发，`L=2` 只需维持 2.5 头杀/s；与每 .10 s 转靶和 9.75/s 枪速相容。**无限指无限供靶/无场末时的数学反例；90 s 局表现为一路开到结算，不是现实里无限长。** |
| 四卡密靶压力测试 | 高手、相同 `H=220`、人枪×2＋战术补给＋欲罢，旧→新：KPM **299.22→147.65**，辅助杀占比 **97%→71%**，实际段长 P90 **83.27→11.04 s** `模`。修复是让爆头项也衰减、辅助不返弹；数学漏洞已封，但此场景依旧偏自动，不能宣布 G2 通过。 |
| **旧战术补给挤掉普通枪械卡** | 熟练稀疏场单卡，旧补给增 KPM/币 **+7.71/+10.55%**，同档旧熟练换弹 **+4.34/+5.24%** `模`；一发一杀时还能抹掉换弹玩法。仅手射返弹后补给 **+3.81/+3.63%**，与新版换弹的 **+4.42/+4.66%** 形成取舍。慢狙和手枪须另测。 |
| **收割者 / 贪婪 / 黄金喷漆 / 双倍饮料** | 收割者单卡就产生 **+25.65%** 币、0 KPM `模`；贪婪、饮料若同时生效又放大整笔收益。金靶只放大致死底薪；限制同名饮料连续生效，查商店实际可花价值。末店后边际效用近零，不能称全程统治。 |
| 玻璃心流、余韵与狂热弹夹 | 旧版「基础翻倍」会产生整场覆盖风险，即使不是数学无限；狂热弹夹原文未定义每杀续几秒，不能宣称算出无限。新版分别用有限增益、退出后必须重新击杀、只准手射按独立几何序列续弹。余韵极限 90%，不能单独自启。 |
| 分裂喷漆 / 极小弹匣 | 若子靶也能分裂或全额充能，会把一杀变无限供靶或刷倍率；若配末发与精简，几乎每杀吃双倍。优先删分裂；若保留，子靶不可递归、不计评分/奖励/续时和倍率，只一次表现。最小弹匣与末发组合单测手射 KPM，别拿峰值掉币当平均。 |
