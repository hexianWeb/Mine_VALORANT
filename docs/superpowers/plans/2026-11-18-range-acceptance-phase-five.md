# 靶场阶段五验收记录：2026-11-18

依据：[靶场挑战设计](../specs/2026-11-16-range-challenges-design.md)。用户确定困难档从 `0.5` 改为 `0.7` 秒并开始验证。规则版本 `range-challenges-v3-2026-11-18`；简单和中等仍为 `2.0/1.0` 秒，固定伤害不变。**本记录是首轮验收，不是全部签收。**

## 已验证

| 项目 | 结果 |
| --- | --- |
| 三档时限 | 60 Hz 固定步下分别为 120／60／42 步。困难档截止前一固定步可接受致死，恰到截止按超时。浏览器从实际面板开启困难档，30 次全超时后以 `0/30` 结束，模拟用时 21 秒；简单、中等在浏览器核验开局、单靶窗口和取消，不是完整成绩局。 |
| 实际房间容量 | 扇形内有 222 个完整候选格，过滤后 167 个合法格；容量诊断给出 26 个可用于保证容量的格子，机器人池为 20 个实例。50／100 两档实际运行中维持 10 只可命中靶，采样中的活靶和退场保护格均不冲突。 |
| 消灭 50／100 | 两档均由实际鼠标射击场景「开始」方框开局，后续使用脚本瞄准与游戏正常武器开火／换弹命令，无注入击杀或改计分。分别达成 `50/50`、`100/100`，验证 49／99 次同固定步补刷、1／4 次手动换弹、50／100 次击杀特效事件；最后一击停表，剩余目标、退场和网格占用最终清空。 |
| 操作与展示 | 框外射击只命中显示面、不触发开始；运行中拒绝打开商店，设置项只读且可以显式取消而不计成绩；Esc 暂停时保留 10 个靶，点击继续后成功捕获鼠标、不产生射击。`100/100` 在计分板与 HUD 均可读。静止 20 个浏览器帧内测得 0 次 HUD DOM 变更、0 次面板重绘／纹理上传请求。 |
| 自动化 | 64 项相关测试通过。规则在 30／60／144 FPS 和五固定步追帧驱动下结果一致，覆盖困难 `0/30`、`23/30`、`30/30` 和消灭 50／100 停表；这不代替浏览器性能验收。源码生产构建通过，未复制 `public`。工作区全量测试 579 项，578 通过，1 项 `tests/weapon-assets.test.mjs:319` 武器材质断言失败，未修改该模块。 |

浏览器使用本地产物、实际 `public` 房间和机器人资源，关闭 probes／AO／AA。证据位于 `D:/opencode-temp/opencode/range-phase-five-20261118/`：`production-smoke/report.json` 保留困难完成及一次鼠标瞄准落在方框外的未通过尝试，`browser-lifecycle/report.json` 补齐设置、取消和暂停检查，`elimination/report.json` 记录两档完整结果并保存截图。
