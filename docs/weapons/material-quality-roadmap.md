# 第一人称武器材质与质感优化路线图

> Classic v4 的 AG、Smite、Sakura 和 Phantom v3 的 Tactiplay、Smite、Rush、Prism 使用相同的默认枪身材质。

## 当前默认材质与验证

- 练枪房默认加载主房间的静态 HDR Cubemap 并生成一张共享 PMREM。捕获点是世界坐标 `[0.5, 10.5, 5.5]`，六面各为 256²，RGBA16F 线性源数据共 3 MiB，位于 `public/lighting/range-room-reflections/v1/`。
- 枪身室内反射倍率为 `0.3`，随全局灯光开关归零或恢复。资源与房间、天空、捕获配置和 Three.js 版本绑定。非 Lightmap 房间、资源失配或加载失败时，枪身使用场景的天空环境，默认强度 `0.35`。
- 当前室内枪身共用主房间单探针。盒投影、走廊探针与空间过渡在后续评估。实时 RectAreaLight 提供顶灯高光，离线捕获保留墙地受光和灯面几何的遮挡。
- 添加 `?reflectionPreview=1` 可在大厅查看原始 HDR 六面。上排为 `+X / +Y / +Z`，下排为 `-X / -Y / -Z`。预览按全局色调映射和 LUT 显示 RGBA16F 源像素，独立于枪身的 PMREM 和反射倍率。
- 下列浏览器检查使用练枪房主页面，验证四款皮肤、HDR 发光和反射贡献、全局灯光开关及切枪换肤时的缓存复用。独立武器预览使用自己的展示灯光。

```powershell
node --test tests/weapon-assets.test.mjs tests/reflection-preview.test.mjs tests/app-config.test.mjs
node tools/check-weapon-lighting-browser.mjs http://localhost:5173/
```

更新静态房间后，可用 `tools/bake-room-reflection.mjs` 捕获新资源。用 `REFLECTION_OUTPUT` 指定候选目录。

## 1. 目标与边界

目标是保留低模场景中的硬朗平面与皮肤图案。实时顶灯和室内反射表现整体金属质感，皮肤自发光维持暗处的颜色可读性。

期望效果：

- 枪械实体部件采用统一的金属方向，通过粗糙度与几何平面区分表面响应；角色手臂保持独立的非金属、哑光表现。
- 平直着色保留平面之间清楚的受光差异。
- 枪身高光反映顶灯、墙面和地面的受光，转身时随观察方向变化。
- 自发光保留暗处的皮肤颜色，明暗层次与高光仍由场景照明决定。
- 亮处保留结构，移动和转身时受光自然变化；不要求皮肤在所有光照下与原 PNG 一样明亮、饱和。
- 待机、ADS、检视和换弹中都保持一致，不仅在某一张截图里好看。

实施边界：

- 不通过提高全局曝光、修改全局 LUT 或强补光掩盖武器问题。
- 不改变枪械玩法、动作时钟、持枪位置或 ADS 投影。
- 不默认重绘现有皮肤；需要新增贴图或修改模型时，单独确认范围。
- 首版不把复杂法线、倒角、视模阴影或每帧反射捕获作为前置条件。
- 角色手臂遵守[手臂 UV 与贴图规范](arm-uv-contract.md)，不混入武器皮肤包。
- 保留视模的独立深度、HDR 合成与世界 AO 隔离，不重新引入贴墙裁切。

## 2. 当前基础与主要瓶颈

当前已具备共享世界灯光、LightProbeGrid 和天空环境的独立视模渲染，材质参数按 weapon / scope / armsLeft / armsRight 角色配置。现行实现以[武器发布与动画播放](animation-and-assets.md)为准。

后续主要评估盒投影、走廊反射过渡，以及枪身部件的粗糙度、接触遮蔽和边缘细节。底色和发光贴图的加载及换肤规则见[皮肤自发光](animation-and-assets.md#皮肤自发光)。

## 3. 优先级

| 优先级 | 工作项 | 主要收益 | 控制范围 |
| --- | --- | --- | --- |
| P0 | 固定对照机位与评价标准 | 避免只针对一张截图反复调参 | 记录现行基线，固定曝光和显示变换 |
| P1 | 平直着色、全金属和皮肤自发光 | 统一运行时枪身材质 | Classic 和 Phantom 的现行皮肤 |
| P1 | 主房间静态反射探针 | 让金属反射与游戏实际房间一致 | 游戏内离线 HDR Cubemap 捕获、PMREM、镜面通道接入 |
| P2 | 盒投影校正与走廊探针 | 改善空间错位和室内外交界 | 单探针验收后再评估，不承诺首版空间精确 |
| P2 | 粗糙度分区与贴图 | 丰富部件层次，不改变全金属方向 | 先参数后贴图，不强制新增金属度遮罩 |
| P2 | 轻量接触遮蔽 | 加强部件嵌合与握持关系 | 不直接复用世界 AO |
| P2 | 适量倒角／法线细节 | 改善边缘高光与结构可读性 | 保留低模轮廓和像素风 |
| P3 | 视模自阴影 | 补充复杂姿态下的体积关系 | 仅在前述手段仍不足时评估 |

## 4. 枪身与手臂的材质基线

### 4.1 平直着色与角色边界

- 枪械采用面法线／硬边方向，保留较大的平面和低模轮廓，不默认沿用平滑法线。
- 枪身实例启用 `flatShading` 并清除法线贴图。
- 检查三角化、镜像、非均匀缩放及动画变形后的高光，避免无意的三角接缝、法线翻转或闪跳。
- 枪械实体部件统一朝金属响应校准，手臂／袖子／手套不纳入这次金属化。未来若有透镜或显示屏等特殊材质，另行确认，不直接套用全金属参数。

### 4.2 默认材质参数

| 项目 | 当前值 |
| --- | --- |
| 枪身金属度 | `1` |
| 枪身粗糙度 | `1` |
| 枪身自发光 | 优先使用皮肤的独立发光图，否则共用当前底色图。发光颜色为白色，默认强度 `0.4` |
| 枪身清漆 | Classic 沿用 GLB 强度约 `0.291`，粗糙度 `0.18`。Phantom 使用无清漆的 Standard 材质 |
| 角色手臂 | 金属度 `0`、粗糙度 `0.96`，使用共享手臂贴图 |

材质实例先应用角色参数，再绑定当前皮肤的纹理。枪身使用实时顶灯的直接镜面贡献和环境反射，手臂继续接收漫反射探针照明。

### 4.3 按需要补充贴图

首版不以新增贴图为前置条件；统一参数与室内反射通过后，优先评估粗糙度分区。既然枪械采用全金属方向，就不必为了实现本方案强制新增金属度遮罩。

| 数据 | 色彩空间 | 用途 |
| --- | --- | --- |
| Base Color／基础颜色 | sRGB | 保留皮肤图案，并参与金属反射着色 |
| Roughness／粗糙度 | 非颜色数据，不做 sRGB 解码 | 控制高光宽度与反射清晰度 |
| Metalness／金属度 | 非颜色数据 | 首版使用统一参数；以后材料方向改变时再决定是否需要遮罩 |
| Normal／法线 | 非颜色数据 | 可选；仅补确有必要的结构，不覆盖平直着色的整体方向 |
| AO／环境遮蔽 | 非颜色数据 | 补充稳定的局部间接光遮蔽 |

可评估使用 ORM 打包：R 为 AO、G 为粗糙度、B 为金属度。是否打包应根据加载与采样实现确定，不在未验证前规定最终资源格式。

注意事项：

- 当前皮肤加载契约需要扩展后才能支持这些可选输入；不能只放入 PNG 就认为运行时会使用。
- 仅提供底色图的皮肤共用该图作为枪身的自发光图。
- 粗糙度和可选遮罩按明确的区域制作，不用基础颜色的明暗直接推断金属度、粗糙度或凹凸。
- 不同皮肤可具有不同粗糙度表现；UV 兼容不代表一定能共用全部材质贴图。
- 基础颜色保持像素锐度；材质遮罩与 UV 边界对齐，避免滤波串色和高频法线闪烁。
- 法线贴图必须验证切线空间、左右镜像 UV、法线方向和 V 翻转约定。

## 5. 反射方案：游戏内离线捕获的静态局部反射探针

### 5.1 Cube Map、Reflection Probe 与 Blender 相机的关系

三者不是互斥的渲染方案：

| 概念 | 职责 | 本方案中的位置 |
| --- | --- | --- |
| HDR Cubemap | 以六个方向表示环境的线性辐亮度 | 游戏内离线捕获的源数据 |
| Reflection Probe | 管理捕获位置、影响范围、反射数据及可选的混合／视差校正 | 运行时的局部镜面环境系统 |
| Blender 全景相机 | 离线生成 HDR 环境图的一种工具 | 本版不作为正式捕获来源；Blender 可用于布置探针 |
| PMREM | 为不同粗糙度预过滤环境反射 | PBR 材质使用的镜面环境，不等同于普通 mipmap 或简单模糊 |

已确认的数据流：

```text
Blender 布置捕获点／影响范围（可选）
                    ↓ 导出位置与范围
游戏实际静态房间 → 离线六向线性 HDR 捕获
                    ↓ 保存版本化源数据
                  PMREM
                    ↓
            静态局部反射探针
                    ↓ 关卡共享给枪身材质
               枪械金属材质
```

开发阶段捕获六面并保存线性 HDR 数据。游戏加载时从已保存的源数据生成 PMREM，资源校验包含 Three.js 版本。

### 5.2 为什么优先从游戏房间捕获

- 当前最终房间使用游戏侧 Lightmap、材质和灯光组合；从游戏捕获能直接反映玩家看到的墙面、地面与顶棚。
- 不把 Blender 中不同的工作室环境、材质响应或光照结果带入枪械反射，减少两套渲染之间的外观漂移。
- 房间资产更新后，可按版本签名重新捕获和验证，形成可重复的发布步骤。
- 引擎捕获只记录已有房间表现，不会自动增加 Cycles 才有的光线追踪效果；这项选择以画面一致性为优先，而非宣称离线质量更高。

若以后统一以 Blender 为照明基准，可以把捕获来源改为场景线性 HDR 全景 EXR，再接入同一探针系统，不必推翻运行时设计。Blender 原生反射探针及其内部烘焙缓存不能视为随 GLB 自动可用的 Three.js 资源。

### 5.3 探针布局与空间覆盖

首版仅完成主房间单探针：

- 水平位置选择玩家主要活动区域的代表点，不机械使用整个建筑的几何中心。
- 高度接近实际持枪高度，不直接使用高大房间的半高；避开墙内、灯具内部和紧贴障碍物的位置。
- 捕获点、影响范围和未来的盒投影边界是不同数据，不能把一个相机的位置当成完整的区域定义。
- 探针布局若来自 Blender，坐标变换与房间 GLB 一致：`(x, y, z) → (x, z, -y)`；捕获方向、面顺序和旋转另行验证。

单张环境图只记录从捕获点向各方向看到的辐亮度，不包含完整的空间深度。枪移到墙边后，墙面和顶灯反射可能错位；提高贴图分辨率不能解决这个视差问题。

后续按实际缺口依次评估：

1. 盒投影校正，改善房间墙地顶的近似空间定位。
2. 走廊独立探针及门口的空间混合；不能仅靠最近探针硬切换。
3. 室外及无有效室内探针区域回退到天空反射。

静态的是捕获结果，不是枪上的高光。转身、检视和换弹仍根据视线与法线实时改变反射；首版不能承诺单探针对所有位置都空间准确。

### 5.4 静态 HDR 捕获规则

1. 使用实际静态房间的材质与 Lightmap，保留墙面、地面、顶棚及其受光结果。
2. 排除第一人称武器、角色、移动道具、探针标记和调试辅助物，避免自我反射或过期动态物体。
3. 捕获保持场景线性 HDR，明确线性 sRGB／Rec.709 约定；不烘入显示曝光、tone mapping、sRGB 编码或显示 LUT，不把大于 `1` 的能量裁成普通 PNG。
4. 捕获副本不能读取正在生成的本探针，避免反馈累加；首版不默认迭代递归反射。
5. PMREM 按粗糙度预过滤捕获结果。更新资源时验证六面接缝、方向、精度和亮部保留。
6. 捕获只因静态房间、Lightmap、灯光或相关配置变化而显式更新，不随切枪、换肤或玩家移动重新捕获。

可用每面 256／512 像素作为成本与质量对照候选，不预先把更高分辨率当作最终质量要求。

### 5.5 光照分工与防止重复计光

| 来源 | 职责 | 边界 |
| --- | --- | --- |
| 实时灯光 | 枪械的直接照明与直接镜面贡献 | 不通过提高全局亮度补偿反射缺失 |
| 静态室内反射探针 | 金属的局部镜面 IBL | 替换或受控混合天空镜面环境，不再无条件叠加整份天空反射 |
| 现有 LightProbeGrid | 非金属物体的局部漫反射间接光 | 继续服务手臂等接收者，不能当成金属镜面反射数据 |
| 枪械自发光 | 在暗处保留皮肤颜色 | 默认强度 `0.4`，可由独立发光图的描述覆盖 |

室内 PMREM 直接绑定到枪身材质，供金属镜面反射和清漆层使用。手臂和瞄具继续使用视模场景的天空环境。

顶灯本体既可能出现在捕获图中，也可能由实时 RectAreaLight 提供直接高光，必须避免同一直接镜面贡献计入两遍。首版已选择实时灯承担直接高光，捕获将灯面设黑而不隐藏几何，保留实体遮挡及墙地面受光；以后如改为由反射图承担灯面亮源，需要重新隔离验证，不能叠加两份完整贡献。

### 5.6 资源与性能边界

- 室内反射归关卡／场景所有，武器实例借用；不同皮肤和双枪不各自复制捕获纹理或 PMREM。
- 探针配置至少描述身份、捕获点、影响范围、方向约定与资源引用；多探针的优先级、过渡宽度及盒投影参数在相应阶段补充。
- 保存房间模型、Lightmap、灯光、捕获设置和预过滤版本的来源签名与资源哈希，避免房间更新后仍使用旧反射而不自知。
- 实测加载／PMREM 生成耗时、运行时 GPU 成本、源数据与预过滤数据显存；静态捕获不代表零运行时成本。
- 生成或加载失败时保留上一份有效数据或明确回退到天空，不发布一半更新的探针；关卡卸载后释放场景所有的资源。

## 6. 后续可选：接触遮蔽与边缘细节

### 6.1 先补接触关系

重点观察握把与手的接触处、弹匣接口、机匣凹槽及部件缝隙。

- 对稳定的枪体结构，优先评估轻量 cavity／烘焙 AO。
- 对随动画变化的手与枪接触关系，再评估视模专用的小尺度屏幕空间遮蔽。
- 半径按武器的厘米级结构标定，不能直接沿用房间 AO 的米级参数。
- 遮蔽作用于对应的间接光，不简单乘黑最终画面；全金属需检查镜面遮蔽，而不是只降低已经很弱的漫反射。检查是否与贴图已有阴影重复。
- 接触处应更清楚，但不能出现大块脏黑、黑色光晕或掏枪时明显闪动。

### 6.2 再补边缘高光

- 仅对需要承接高光的边缘增加适量倒角，或将细节烘焙到法线。
- 保留平直着色与硬朗轮廓，不全局平滑、磨圆、细分或添加写实微噪声；法线细节不是新基线的默认组成部分。
- 划痕、磨损和露底金属应具有材料依据，不把随机噪声当作质感。
- 修改拓扑、UV 或模型时，重新核对兼容签名并发布新版本，不能伪装成只换贴图。

自阴影放在后续可选项中：只有上述措施仍无法表达体积关系时，才评估独立、稳定的视模阴影方案，并防止世界墙面遮挡破坏视模可读性。

## 7. 稳定的材质与反射校准流程

### 7.1 实时调试

建议在现有「武器 · 场景光照」基础上增加：

- 枪械粗糙度参数／贴图倍率、平直着色对照；金属度按新基线固定，调试修改不能误保存为另一种材料方向。
- 室内反射、天空反射、实时顶灯及探针漫反射的独立对照，显示当前选中的反射探针与是否回退。
- 探针捕获点、影响范围和环境图预览；支持核对方向与六面接缝。
- 清漆和自发光实际状态检查，确认导入、切枪与换肤后仍符合基线；暗部补光保留隔离诊断用途，不作为金属保亮方案。
- 单项对照、恢复默认值和记录候选配置；后续加入盒投影或多探针时再补对应控件。

参数应更新实例材质或 uniform，避免每次拖动都重建模型、播放器或整条渲染管线。实时效果与保存为项目默认值分开处理，避免无意覆盖正在进行的美术调参。

控件须验证实际影响枪械实例，包括导入的 Physical 材质及其 NodeMaterial 路径；面板数值变化但只影响房间／茶壶，不能作为接入成功的依据。实时材质倍率与“重新捕获并发布静态资源”也必须分开。

### 7.2 对照矩阵

| 维度 | 最少覆盖 |
| --- | --- |
| 光照位置 | 顶灯下、室内暗部、走廊／门口、室外 |
| 视角 | 正常持枪、转向不同灯光方向、上下观察 |
| 动作 | 待机、ADS、检视、换弹、射击 |
| 皮肤 | 深色、浅色与高对比图案，避免只针对一款校准 |
| 反射来源 | 仅天空、仅室内、关闭镜面环境；实时顶灯单独开关 |
| 空间限制 | 捕获点附近、墙边、房间两端；盒投影／区域混合阶段另加对应对照 |
| 运行状态 | 切枪、换肤、Editor 返回、暂停／恢复、窗口缩放 |

固定相机、姿态、曝光、LUT、分辨率和效果开关，保存修改前后截图。必要时先用中性调色排查，再回到正式显示配置验收；不要为了枪身改变整个场景的视觉基准。

## 9. 工程与验收要求

可能涉及的代码入口：

- `src/game/weapons/assets/weapon-materials.js`：平直着色、全金属与清漆／发光基线。
- `src/game/weapons/assets/weapon-assets.js`：皮肤加载契约、换肤覆盖顺序、可选粗糙度输入与资源归属。
- `src/engine/runtime/function/render/passes/viewmodel-pass.js`：世界空间反射、视模光照、独立深度与效果隔离。
- `src/game/range-room/lighting/`：静态局部反射、区域选择及与现有漫反射探针的分工。
- `src/engine/editor/panels/render-panel.js`：材质与反射实时校准、来源及状态对照。
- `tools/bake-room-reflection.mjs`：生成静态 HDR 捕获与来源记录。
- `tools/weapons/`：确有枪械资产变更时的版本化发布与完整性验证；场景反射资源不重复打包到每个皮肤。

工程边界：

- 武器皮肤不能覆盖共享角色手臂；遵守已有 UV、镜像方向与纹理所有权契约。
- 换肤保持原子性，不能出现颜色已换、其他材质贴图仍属于旧皮肤的中间状态。
- 不覆盖已发布资产版本，不绕过 manifest、哈希及兼容性校验。
- 更新房间或灯光后必须检查反射来源签名；不能静默沿用不匹配的捕获。预过滤缓存绑定相应算法与版本。
- 制作源的修改须先明确范围并备份；截图、捕获、候选资源和临时报告放在 `D:/opencode-temp/opencode/`。
- 每项新增效果单独计时，检查反复切枪／换肤后的纹理、材质和渲染目标是否增长。

新增验收至少覆盖：

- 关闭直接光和镜面环境后，验证枪身的 HDR 自发光与当前皮肤及其强度一致。
- 分别验证枪身的室内镜面反射和视模的漫反射探针贡献。
- 平直法线在待机、ADS、检视、换弹中稳定；换肤不重建骨架或破坏已有动作与采样。
- 室内反射开关实际影响武器镜面路径，不意外替换手臂漫反射或叠加天空；顶灯直接贡献不存在未经说明的重复计光。
- HDR 能量、六面方向、接缝及预过滤粗糙度响应正确；tone mapping 与显示变换仍只在最终管线执行。
- 捕获不包含动态物体或自身反馈；重捕获可重复、来源可追踪，失败回退与关卡释放不泄漏资源。
- 单探针、盒投影和多探针分阶段验收，不把尚未实施的空间校正算作首版已实现能力。
